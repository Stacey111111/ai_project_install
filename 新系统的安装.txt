Part 1: Install Dependencies in Docker Container
    在Docker容器中安装依赖

────────────────────────────────────────────────────────────
 
Step 1: Enter Docker container
步骤1：进入Docker容器
 
docker exec -it <container_name> bash
 
 
Step 2: Install Python dependencies
步骤2：安装Python依赖
 
⚠️  Use --break-system-packages flag if needed
    如果需要，使用--break-system-packages标志
 
# Method 1: Standard installation (try this first)
# 方法1：标准安装（先尝试这个）
pip3 install mediapipe opencv-python numpy torch
 
# Method 2: If you get "externally-managed-environment" error
# 方法2：如果遇到"externally-managed-environment"错误
pip3 install --break-system-packages mediapipe opencv-python numpy torch
 
# Method 3: Use virtual environment (most recommended)
# 方法3：使用虚拟环境（最推荐）
python3 -m venv ~/ros2_venv
source ~/ros2_venv/bin/activate
pip3 install mediapipe opencv-python numpy torch

💾 Part 4: SAVE Docker Container (IMPORTANT!)
    保存Docker容器（重要！）
────────────────────────────────────────────────
 
⚠️  After installing all dependencies and building the package,
    SAVE your Docker container as a new image!
    在安装所有依赖并编译包后，将Docker容器保存为新镜像！
 
This ensures you don't lose your work when the container is stopped.
这确保容器停止时不会丢失您的工作。
 
 
Method 1: Commit Container to Image (Recommended)
方法1：将容器提交为镜像（推荐）
─────────────────────────────────────────────────
 
# Exit container first
# 先退出容器
exit
 
# On HOST machine, commit the container
# 在宿主机上，提交容器
docker commit <container_name> ros2_gesture_control:v1.0
 
# Verify new image
# 验证新镜像
docker images | grep ros2_gesture_control
 
# Should see:
# ros2_gesture_control  v1.0  <image_id>  Just now  <size>
 
 
# Optional: Add metadata
# 可选：添加元数据
docker commit \
  -m "Added robotics_project_ai with hybrid navigation" \
  -a "Your Name" \
  <container_name> \
  ros2_gesture_control:v1.0

🔄 Part 5: Use Saved Image
    使用保存的镜像
────────────────────────────────────────────────
 
After saving the image, use it instead of the old image:
保存镜像后，使用它代替旧镜像：
 
 
Stop and remove old container:
停止并删除旧容器：
 
docker stop <container_name>
docker rm <container_name>
 
 
Start new container with saved image:
使用保存的镜像启动新容器：
 
xhost +local:docker
 
docker run -it \
  --name ros2_workstation \
  --network host \
  --device=/dev/video0:/dev/video0 \
  -e DISPLAY=$DISPLAY \
  -v /tmp/.X11-unix:/tmp/.X11-unix:rw \
  -v /path/to/your/code:/workspace \
  --privileged \
  ros2_gesture_control:v1.0 \
  bash
 
 
Verify everything is still there:
验证一切都还在：
 
# Inside new container
source /opt/ros/foxy/setup.bash
source ~/ros2_ws/install/setup.bash
 
ros2 pkg list | grep robotics_project_ai
# Should output: robotics_project_ai ✅
 
# Check Python packages
pip3 list | grep -E "mediapipe|opencv|torch"
# Should show all installed packages

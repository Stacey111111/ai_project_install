🔧 Part 1: Install Dependencies in Docker Container
    在Docker容器中安装依赖
────────────────────────────────────────────────────────────

Step 1: Enter Docker container
步骤1：进入Docker容器

docker exec -it <container_name> bash


Step 2: Install Python dependencies
步骤2：安装Python依赖

⚠️  Use --break-system-packages flag if needed
    如果需要，使用--break-system-packages标志

# Method 1: Standard installation (try this first)
# 方法1：标准安装（先尝试这个）
pip3 install mediapipe opencv-python numpy torch

# Method 2: If you get "externally-managed-environment" error
# 方法2：如果遇到"externally-managed-environment"错误
pip3 install --break-system-packages mediapipe opencv-python numpy torch

# Method 3: Use virtual environment (most recommended)
# 方法3：使用虚拟环境（最推荐）
python3 -m venv ~/ros2_venv
source ~/ros2_venv/bin/activate
pip3 install mediapipe opencv-python numpy torch


Step 3: Install optional GPU support (if you have NVIDIA GPU)
步骤3：安装可选的GPU支持（如果有NVIDIA GPU）

# Check if GPU is available
nvidia-smi

# If GPU is available:
pip3 install --break-system-packages torch torchvision --index-url https://download.pytorch.org/whl/cu118

# If no GPU (CPU only is fine):
# 如果没有GPU（仅CPU也可以）：
# Skip this step - the CPU version is already installed
# 跳过此步骤 - CPU版本已经安装


Step 4: Install ROS2 tools (optional, for debugging)
步骤4：安装ROS2工具（可选，用于调试）

# Try without sudo first
apt update
apt install -y ros-foxy-rqt*

# If permission denied, you may be running as non-root user
# 如果提示权限不足，您可能以非root用户运行

# Solution: Exit and re-enter as root
# 解决方案：退出并以root身份重新进入
exit
docker exec -it -u root <container_name> bash

# Then install
apt update
apt install -y ros-foxy-rqt*

📦 Part 2: Setup Project in Docker
    在Docker中设置项目
────────────────────────────────────────────────

Step 1: Navigate to workspace
步骤1：进入工作空间

cd ~/ros2_ws/src


Step 2: Create project directory
步骤2：创建项目目录

mkdir -p robotics_project_ai
cd robotics_project_ai


Step 3: Create directory structure
步骤3：创建目录结构

mkdir -p robotics_project_ai
mkdir -p resource
mkdir -p launch
mkdir -p models

# Create required empty files
touch robotics_project_ai/__init__.py
touch resource/robotics_project_ai


Step 4: Copy files from host to container
步骤4：从宿主机复制文件到容器

⚠️  Important: Files need to be copied INTO the container
    重要：文件需要复制到容器内

# On HOST machine (not inside Docker):
# 在宿主机上（不是Docker内）：

# Method 1: Using docker cp
# 方法1：使用docker cp
docker cp ~/Downloads/hand_gesture_ai_node.py \
  <container_name>:/root/ros2_ws/src/robotics_project_ai/robotics_project_ai/

docker cp ~/Downloads/robot_controller_hybrid_node.py \
  <container_name>:/root/ros2_ws/src/robotics_project_ai/robotics_project_ai/

docker cp ~/Downloads/hybrid_navigation.py \
  <container_name>:/root/ros2_ws/src/robotics_project_ai/robotics_project_ai/

docker cp ~/Downloads/robotics_project_ai_package.xml \
  <container_name>:/root/ros2_ws/src/robotics_project_ai/package.xml

docker cp ~/Downloads/robotics_project_ai_setup.py \
  <container_name>:/root/ros2_ws/src/robotics_project_ai/setup.py

docker cp ~/Downloads/robotics_project_ai_setup.cfg \
  <container_name>:/root/ros2_ws/src/robotics_project_ai/setup.cfg


# Method 2: If files are already in a mounted volume
# 方法2：如果文件已经在挂载的卷中

# Inside container:
# 容器内：
cp /workspace/Downloads/*.py robotics_project_ai/
cp /workspace/Downloads/robotics_project_ai_package.xml package.xml
cp /workspace/Downloads/robotics_project_ai_setup.py setup.py
cp /workspace/Downloads/robotics_project_ai_setup.cfg setup.cfg


Step 5: Verify file structure
步骤5：验证文件结构

# Inside container
tree ~/ros2_ws/src/robotics_project_ai/

# Should look like:
# robotics_project_ai/
# ├── package.xml
# ├── setup.py
# ├── setup.cfg
# ├── resource/
# │   └── robotics_project_ai
# ├── robotics_project_ai/
# │   ├── __init__.py
# │   ├── hand_gesture_ai_node.py
# │   ├── robot_controller_hybrid_node.py
# │   └── hybrid_navigation.py
# └── launch/

🏗️ Part 3: Build Package in Docker
    在Docker中编译包
────────────────────────────────────────────────

Step 1: Source ROS2
步骤1：Source ROS2

source /opt/ros/foxy/setup.bash


Step 2: Build package
步骤2：编译包

cd ~/ros2_ws
colcon build --packages-select robotics_project_ai


Step 3: Source workspace
步骤3：Source工作空间

source install/setup.bash


Step 4: Verify installation
步骤4：验证安装

ros2 pkg list | grep robotics_project_ai
# Should output: robotics_project_ai ✅

ros2 pkg executables robotics_project_ai
# Should output:
# robotics_project_ai hand_gesture_ai_node ✅
# robotics_project_ai robot_controller_hybrid_node ✅

💾 Part 4: SAVE Docker Container (IMPORTANT!)
    保存Docker容器（重要！）
────────────────────────────────────────────────

⚠️  After installing all dependencies and building the package,
    SAVE your Docker container as a new image!
    在安装所有依赖并编译包后，将Docker容器保存为新镜像！

This ensures you don't lose your work when the container is stopped.
这确保容器停止时不会丢失您的工作。


Method 1: Commit Container to Image (Recommended)
方法1：将容器提交为镜像（推荐）
─────────────────────────────────────────────────

# Exit container first
# 先退出容器
exit

# On HOST machine, commit the container
# 在宿主机上，提交容器
docker commit <container_name> ros2_gesture_control:v1.0

# Verify new image
# 验证新镜像
docker images | grep ros2_gesture_control

# Should see:
# ros2_gesture_control  v1.0  <image_id>  Just now  <size>


# Optional: Add metadata
# 可选：添加元数据
docker commit \
  -m "Added robotics_project_ai with hybrid navigation" \
  -a "Your Name" \
  <container_name> \
  ros2_gesture_control:v1.0


Method 2: Export Container to File (Backup)
方法2：导出容器到文件（备份）
─────────────────────────────────────────────

# Export container to tar file
# 导出容器到tar文件
docker export <container_name> > ~/ros2_container_backup.tar

# Compress for smaller size
# 压缩以减小文件大小
gzip ~/ros2_container_backup.tar

# To restore later:
# 稍后恢复：
# cat ros2_container_backup.tar | docker import - ros2_restored:latest


Method 3: Save Image to File (For Transfer)
方法3：保存镜像到文件（用于传输）
──────────────────────────────────────────────

# After committing to image (Method 1)
# 在提交为镜像后（方法1）

# Save image to file
# 保存镜像到文件
docker save -o ~/ros2_gesture_control_v1.0.tar ros2_gesture_control:v1.0

# Compress
# 压缩
gzip ~/ros2_gesture_control_v1.0.tar

# To load on another machine:
# 在另一台机器上加载：
# docker load -i ros2_gesture_control_v1.0.tar.gz

🔄 Part 5: Use Saved Image
    使用保存的镜像
────────────────────────────────────────────────

After saving the image, use it instead of the old image:
保存镜像后，使用它代替旧镜像：


Stop and remove old container:
停止并删除旧容器：

docker stop <container_name>
docker rm <container_name>


Start new container with saved image:
使用保存的镜像启动新容器：

xhost +local:docker

docker run -it \
  --name ros2_workstation \
  --network host \
  --device=/dev/video0:/dev/video0 \
  -e DISPLAY=$DISPLAY \
  -v /tmp/.X11-unix:/tmp/.X11-unix:rw \
  -v /path/to/your/code:/workspace \
  --privileged \
  ros2_gesture_control:v1.0 \
  bash


Verify everything is still there:
验证一切都还在：

# Inside new container
source /opt/ros/foxy/setup.bash
source ~/ros2_ws/install/setup.bash

ros2 pkg list | grep robotics_project_ai
# Should output: robotics_project_ai ✅

# Check Python packages
pip3 list | grep -E "mediapipe|opencv|torch"
# Should show all installed packages

📋 Part 6: Quick Reference - Docker Save Commands
    快速参考 - Docker保存命令
────────────────────────────────────────────────────────

# 1. Commit running container to image
#    将运行中的容器提交为镜像
docker commit <container_name> <new_image_name>:<tag>

# 2. Save image to file
#    保存镜像到文件
docker save -o <filename>.tar <image_name>:<tag>

# 3. Load image from file
#    从文件加载镜像
docker load -i <filename>.tar

# 4. List all images
#    列出所有镜像
docker images

# 5. Tag image with new name
#    用新名称标记镜像
docker tag <old_name>:<old_tag> <new_name>:<new_tag>

# 6. Remove old image
#    删除旧镜像
docker rmi <image_name>:<tag>

⚠️  Important Notes - Docker Environment
    重要说明 - Docker环境
────────────────────────────────────────────────

1. Virtual Environment (Recommended):
   虚拟环境（推荐）：

   Using a Python virtual environment is the cleanest approach:
   使用Python虚拟环境是最干净的方法：

   python3 -m venv ~/ros2_venv
   source ~/ros2_venv/bin/activate
   pip3 install mediapipe opencv-python numpy torch

   Add to ~/.bashrc for automatic activation:
   添加到~/.bashrc以自动激活：

   echo "source ~/ros2_venv/bin/activate" >> ~/.bashrc


2. Persistent Data:
   持久化数据：

   Data in Docker containers is NOT persistent unless:
   Docker容器中的数据不是持久的，除非：

   a) You commit the container to an image (docker commit)
      将容器提交为镜像

   b) Data is in a mounted volume (-v flag)
      数据在挂载的卷中

   c) You explicitly save files to host
      显式保存文件到宿主机


3. Network Mode:
   网络模式：

   MUST use --network host for ROS2 communication
   必须使用--network host以进行ROS2通信


4. Camera Access:
   摄像头访问：

   MUST use --device=/dev/video0:/dev/video0
   必须使用--device=/dev/video0:/dev/video0


5. X11 Display:
   X11显示：

   MUST run: xhost +local:docker on host before starting container
   必须在启动容器前在宿主机上运行：xhost +local:docker

🎯 Part 8: Complete Installation Script
    完整安装脚本
────────────────────────────────────────────────

Save this as install_in_docker.sh and run inside Docker container:
保存为install_in_docker.sh并在Docker容器内运行：

```bash
#!/bin/bash

echo "Starting installation in Docker container..."

# 1. Install Python dependencies
echo "Installing Python packages..."
pip3 install --break-system-packages mediapipe opencv-python numpy torch

# 2. Create project structure
echo "Creating project structure..."
cd ~/ros2_ws/src
mkdir -p robotics_project_ai
cd robotics_project_ai

mkdir -p robotics_project_ai resource launch models
touch robotics_project_ai/__init__.py
touch resource/robotics_project_ai

# 3. Notify user to copy files
echo ""
echo "⚠️  Now copy your files to this directory:"
echo "   ~/ros2_ws/src/robotics_project_ai/"
echo ""
echo "Press Enter when files are copied..."
read

# 4. Build package
echo "Building package..."
cd ~/ros2_ws
source /opt/ros/foxy/setup.bash
colcon build --packages-select robotics_project_ai

# 5. Source workspace
echo "Sourcing workspace..."
source install/setup.bash

# 6. Verify
echo "Verifying installation..."
ros2 pkg list | grep robotics_project_ai

echo ""
echo "✅ Installation complete!"
echo ""
echo "⚠️  IMPORTANT: Exit container and save it:"
echo "   exit"
echo "   docker commit <container_name> ros2_gesture_control:v1.0"
echo ""
```
